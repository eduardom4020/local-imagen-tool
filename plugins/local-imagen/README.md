# local-imagen

Local image generation for Claude Code: ComfyUI (Docker) + FLUX.2 klein 4B. Images live in game projects whose
style guide (styles, characters, creatures, locations, props, poses, cameras) you manage by chatting. Every Claude
session is isolated, and a private best-of-N picker (the `image-picker` agent) shows you only the best candidate.

After installing, ask Claude to "set up the local image generator" (the `local-imagen-setup` skill runs
`scripts/setup.py`). Full documentation: the README at the root of the marketplace repository.
